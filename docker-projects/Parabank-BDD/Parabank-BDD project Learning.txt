1. datatable scenario: provide inputs in feature file in 2 columns if using datatable.rowsHash()(It don't accept multiple columns and test will fail)
2. multiple columns works if using datatable.hashes()[0] (have to give [0] even if one row is given)
3. tags:
     - tags are useful to run specific scenarios
     - OR behavior : --tags "@negative or @profile" --> It runs negative scenario and profile scenario independently (No connection between them)
     - single tag :  --tags "@profile" - runs only profile scenario 
     - AND behavior : --tags "@negative and @profile" --> Runs ONLY scenarios having BOTH tag otherwise it states 0 scenarios and 0 steps.
     - tags do no control execution flow (scenario 1 runs independently and scenario 2 runs independently)
