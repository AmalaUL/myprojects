# Expense Tracker (JavaScript)
This is a simple Expense Tracker application built using vanilla JavaScript.
It allows users to add expenses, categorize them, and calculate the total amount.

## Features
- Add expense with:
Description
Category (Food, Travel, Shopping, Other)
Amount
- Display expenses in a table
- Calculate total expense
- Auto-clear input fields after adding

## Tech Stack
JavaScript (Vanilla JS)
HTML DOM Manipulation

## How to Run
Create an index.html file
Add this script inside <script> tag or link JS file
Open the file in browser

## How It Works
- Click Add Expense → Adds a new row in table
- Click Total Expense → Displays total amount below table
Example
Description: Lunch
Category: Food
Amount: 200
- Added to table and included in total

## Key Concepts Used
DOM manipulation (createElement, appendChild)
Event handling (addEventListener)
Looping through table rows
Dynamic UI creation
