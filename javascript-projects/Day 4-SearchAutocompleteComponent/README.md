# Search Autocomplete Component (JavaScript)
This project demonstrates a basic Search Autocomplete behavior using vanilla JavaScript, focusing on performance optimization with debounce and state management using closures.

## Features
Real-time input handling
Debounced search (reduces unnecessary function calls)
Maintains search history
Console logs search inputs

## Tech Stack
JavaScript (Vanilla JS)
DOM Manipulation

## How to Run
Create an index.html file
Add this script inside a <script> tag or link it as a JS file
Open the file in browser
Type in the input box and check console for output

## How It Works
- Debounce Function
- Delays execution of function until user
